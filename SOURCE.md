# Source provenance

The initial plugin payload is an unchanged export of **send2ereader.koplugin/** from the authoritative ThinkForge **send2ereader_v2** workspace at commit **a01daf9**.

All 17 source files, including runtime Lua modules, icons, and the four Lua test files, were copied without modification. The standalone repository adds public documentation, verification/build scripts, and GitHub Actions using the packaging conventions established by **jadehawk/libby-dashboard.koplugin** and **jadehawk/deluxe-sync.koplugin**.

The release ZIP contains README.md and send2ereader.koplugin/. Server code, CrossPoint code, local references, workspace instructions, credentials, and Git metadata are not included.
